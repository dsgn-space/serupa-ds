Details that read as one system across the patterns and blocks:

- Footer link lists, and the links in every pattern's page bar, underline on hover only, as navigation does; links in running text keep their underline.
- A Copy button beside a field or a medium button is that height too: Referral's "Copy link", API keys' "Copy the key", Account security's "Copy the codes" and Share dialog's "Copy link".
- StatsRow fits its grid to the count: two or three numbers share one row from sm, so a third no longer sits alone under two; four or more go two, then four across.
- Support ticket names your own messages "You" once, then the time, not "You You, …".
- Store locator's opening hours fold under the system's disclosure (Accordion: its chevron, focus ring and motion) instead of the browser's triangle, and today is bold at the list's own size.
- Permission request says the call's time in the reader's clock (3:00 – 3:30 PM, or 15:00–15:30), not a fixed "15.00–15.30".
- Sign up's "Send a new code" is an outline button, as Password reset's "Send it again" is, so the code step's actions line up with Verify.
