Five new patterns to copy: Contact form, Address book, Order history, Return request and Referral. The contact form asks for an order number only for an order, and shows a summary of what's missing that takes focus. The address book keeps a default that can't be removed, a dialog whose fields say what they are for autofill, and removes with Undo. Order history finds orders by number, item or state, says how many match, and moves focus to the first new order on Show more. A return request asks why for each item chosen, by its name, disables what can't go back with the reason, and works out the refund as you choose. Referral puts your invite link in a labelled field with Copy, names a bad or repeated address before sending, and says where each friend is in words.
