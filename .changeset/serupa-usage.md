Added: `serupa-usage` shows how a product uses Serupa. `npx serupa-usage src` lists each component it renders, how often, in how many files and with which props, the components it never uses, and the plain elements (`<button>`, `<input>`, `<a>`…) it writes where a component would do. `--json` prints the same numbers for a dashboard.
