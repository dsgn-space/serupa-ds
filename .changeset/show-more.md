Added: ShowMore (beta), for long text such as a description or a review. It shows the first few lines (`lines`, 3 by default) and a "Show more" button only when the text is cut; the button opens the rest and says so to screen readers with `aria-expanded`. It can be controlled with `expanded` and `onExpandedChange`, and its labels come in every language pack.
