Two new patterns. File browser: a folder's files in a list with rows to pick, to move or delete several at once with Undo, and rename, move and delete on each row; focus stays in the list. Task board: a team's tasks in Kanban columns that are saved as they move; a move that can't be saved goes back and says so, a column over its limit says what to do, and a new task is added from a dialog.
