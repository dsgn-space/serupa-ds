Chat: an assistant's reply can show its work. ChatMessage takes `thinking` ("Thinking…" until its words arrive), `reasoning` with `reasoningTime` (a closed "Thought for 12 seconds" section) and `steps` (the tools it called, each in progress, done or failed, said in words). The new ChatSteps draws that list on its own. The README shows a model picker and a context Meter in the composer.
