Component tokens name the state last, as most already did: `--button-bg-disabled`, `--button-text-disabled` and `--button-border-disabled` (were `--button-disabled-bg`, `-text`, `-border`), `--avatar-group-more-bg-hover` (was `--avatar-group-more-hover-bg`), `--carousel-dot-width-active` (was `--carousel-dot-active-width`) and `--data-grid-bg-selected` (was `--data-grid-selected-bg`). The old names still work, read when the new one isn't set, and are removed in 15.0.0.
