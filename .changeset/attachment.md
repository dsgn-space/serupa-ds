- Added: Attachment (beta), a file as one compact row: an icon for its kind (PDF, image, spreadsheet, document, slides, archive, code, audio, video or other, from the MIME type or the extension), the name cut in the middle so the extension stays, the kind and size in the locale's units, an upload bar, a failed state with "Try again", and a remove button. With 14 component tokens. `attachmentKind(name, type)` returns the kind on its own.
