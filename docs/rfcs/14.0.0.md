# RFC: 14.0.0

**Status:** Released in 14.0.0 (3 November 2026).

The next major moves the masks and gradients into their own stylesheet, and has Combobox draw only the options in view instead of the first 100. Neither changes what people see on a page that keeps its imports and its labels up to date; both need a line or two changed by hand.

## Masks and gradients in their own file (`.changeset/l8e141-utilities-extra.md`, pull request #1348)

- **What breaks:** `mask-*`, `bg-linear-*`, `bg-radial*`, `bg-conic*` and the `from-`, `via-` and `to-` stops leave `bundle.css` and `utilities.css` for `utilities-extra.css`. A page using them loses them until it imports that file.
- **Why:** they are a quarter of the utility rules (about 530 KB of `bundle.css`'s 1.76 MB), and few pages use them.
- **Migration:** search the sources for those prefixes; if any appear, import `serupa-ds/utilities-extra.css` after the bundle. By hand: `serupa-migrate` can't tell where a project loads its CSS, but it now lists the files that use those classes.

## Combobox draws only the options in view (`.changeset/l8e146-combobox-windowed.md`)

- **What breaks:** the `moreResults` label and the "Keep typing to narrow N more" line are gone, and the list's popup is a flex column whose `.dk-combobox__listbox` scrolls.
- **Why:** past the first 100 matches, scrolling and the arrow and Page keys couldn't reach the rest of a long list; now every match can be reached and the highlighted one is always drawn, as in VirtualList.
- **Migration:** remove `moreResults` from a labels object passed to `<SerupaProvider labels>` (TypeScript flags it), drop any rule for `.dk-combobox__more`, and move an `overflow` or `max-height` set on `.dk-combobox__popup` to the listbox; `--combobox-listbox-max-height` still sets the height. By hand; `serupa-migrate` lists the lines that name `moreResults` or `.dk-combobox__more`.
