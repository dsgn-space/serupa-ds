# RFC: 17.0.0

**Status:** Released in 17.0.0 (22 November 2026).

The third scheduled major: the cleanups React 19 and earlier deprecations made possible. Components become plain function components that take `ref` as a prop, the names deprecated for 17.0.0 go, and Accordion opens any number by default. Every breaking changeset until the release adds a section here.

## Components take ref as a prop (`.changeset/components-take-ref-as-prop.md`)

- **What breaks:** every component's type is `React.FC<XProps & React.RefAttributes<T>>`, not a `React.ForwardRefExoticComponent`. Code that names that type or reads `.render` or `$$typeof` from a component breaks. Passing `ref`, `React.ComponentRef<typeof X>`, `React.ComponentProps<typeof X>`, `React.memo` and wrappers keep working, and nothing renders differently.
- **Why:** React 19 deprecates `forwardRef`, and the package already requires React 19. As plain functions, the components are seen by the React Compiler and its lint rules (only the shared hooks were before), which is the first step to shipping compiled output.
- **Migration:** by hand, only where code names the forwardRef type: use `typeof X` or `React.ComponentProps<typeof X>` instead (by hand)

## The names deprecated for 17.0.0 are removed (`.changeset/removed-names-17.md`)

- **What breaks:** `TimelineItem`'s `status` and the `TimelineStatus` type, `Combobox`'s `onInputChange`, and `PasswordInput`'s `visible`, `defaultVisible` and `onVisibleChange`. Each has warned in development since it was deprecated, naming its replacement.
- **Why:** one idea, one name: `tone` for a color's meaning, `onInputValueChange` for `inputValue`, and `revealed` as MaskedValue says it.
- **Migration:** `serupa-migrate` renames each one (`serupa-migrate` makes it)

## Accordion opens any number and leaves the arrow keys to the page (`.changeset/accordion-multiple-tab.md`)

- **What breaks:** an Accordion with no `selectionMode` (`type` in 16.x) is `"multiple"`: opening one item leaves the others open. Up, Down, Home and End no longer move between titles; Tab does, as between any buttons.
- **Why:** people compare items, and closing one as another opens takes away what they were reading; the modern web guidance says to avoid exclusive accordions, and that arrow keys on a disclosure's button should scroll the page. The WAI-ARIA pattern marks the arrow keys optional.
- **Migration:** `serupa-migrate --from 16` adds `selectionMode="single"` to each Accordion with no `type` (`serupa-migrate` makes it)

## The `dk` prefix is `srp` (`.changeset/prefix-srp.md`)

- **What breaks:** every class (`dk-btn` → `srp-btn`), internal custom property (`--dk-*` → `--srp-*`), data attribute (`data-dk-*` → `data-srp-*`), generated id and cascade layer (`dk.components` → `srp.components`, and `dk` in an `@layer` order). The design tokens and the component tokens keep their names.
- **Why:** the prefix was the initials of the system's first name; `srp` says Serupa, as the package, the CLI and the theme key do. No layer of `--dk-*` aliases: it would double every internal property for one release, and the classes change at the same time anyway.
- **Migration:** `serupa-migrate --from 16` rewrites them in CSS, markup and code (`serupa-migrate` makes it)

## Brands other than blue are opt-in files (`.changeset/brands-and-palette-opt-in.md`)

- **What breaks:** `tokens.css` has the blue brand only; each other brand is `brands/<brand>.css`, loaded after it (`brands/all.css` has them all).
- **Why:** an app loaded all 17 brands to use one. `tokens.css` drops from 15.1 KB to 11.1 KB gzipped. From the deep audit of 21 Nov 2026, approved by Diki.
- **Migration:** one import per brand the app uses, after `tokens.css` (`serupa-migrate` lists each file that needs one)

## The utility classes nothing used are removed (`.changeset/utilities-trimmed.md`)

- **What breaks:** the palette-step color classes (`bg-red-500`), masks, gradients, filters, transforms but translate, columns and breaks, blend modes, text and inner shadows and tab sizes, and `utilities-extra.css`.
- **Why:** the system uses 221 of about 28,000 classes and none of these; a palette step doesn't follow the theme. `bundle.css` goes from 1.70 MB to 1.10 MB. The tokens stay.
- **Migration:** a role class for a color, or the property in the app's own CSS from the tokens (`serupa-migrate` lists each file that uses a removed class)

## One name and one callback shape for each idea (`.changeset/api-names-17.md`)

- **What breaks:** `leftIcon`/`rightIcon` are `startIcon`/`endIcon` (and the `--left`/`--right` classes `--start`/`--end`), the nav items' `active` is `current`, Text's `tone="default"` is `"neutral"`, and eleven callbacks pass a details object as their second argument (`{ iso }`, `{ event }`, `{ range }`, `{ page }`).
- **Why:** the deep audit of 21 Nov 2026 found the same idea under two names and callbacks of two shapes; `start` and `end` follow the reading direction. Button keeps `variant` and `destructive` (Diki's choice).
- **Migration:** `serupa-migrate --from 16` renames the props and the tone, and lists each handler that reads a callback's second argument (`serupa-migrate` makes the renames and lists the handlers)

## Six more props take the shared name (`.changeset/api-names-17-round-2.md`)

- **What breaks:** Accordion and ToggleGroup `type` is `selectionMode`; BottomNav, Carousel, Toaster and AvatarGroup `label` is `aria-label`; Switch `labelPosition` is `labelPlacement`; MentionInput `trigger` is `triggerChar`; TableSelectCell and TableExpandCell `header` is `inHeader`; ListLoadingItems `description` is `showDescription`; Drawer's `left` and `right` are `start` and `end`.
- **Why:** the deep audit of 21 Nov 2026 found one idea under two names, or one name with two types.
- **Migration:** `serupa-migrate --from 16` renames them on the tags (`serupa-migrate` makes the renames)

## Danger interrupts, everything else waits (`.changeset/danger-interrupts.md`)

- **What breaks:** Alert with `tone="warning"` is `role="status"`, not `role="alert"`; SaveStatus says its error assertively.
- **Why:** the deep audit of 21 Nov 2026 found a warning that interrupted in Alert and waited in Toast, and a failed save said more quietly than a toast about the same failure.
- **Migration:** nothing to rename. A warning that must interrupt passes `role="alert"`.
