# RFC: 17.0.0

**Status:** Open for comments

The third scheduled major: the cleanups React 19 and earlier deprecations made possible. Components become plain function components that take `ref` as a prop, the names deprecated for 17.0.0 go, and Accordion opens any number by default. Every breaking changeset until the release adds a section here.

## Components take ref as a prop (`.changeset/components-take-ref-as-prop.md`)

- **What breaks:** every component's type is `React.FC<XProps & React.RefAttributes<T>>`, not a `React.ForwardRefExoticComponent`. Code that names that type or reads `.render` or `$$typeof` from a component breaks. Passing `ref`, `React.ComponentRef<typeof X>`, `React.ComponentProps<typeof X>`, `React.memo` and wrappers keep working, and nothing renders differently.
- **Why:** React 19 deprecates `forwardRef`, and the package already requires React 19. As plain functions, the components are seen by the React Compiler and its lint rules (only the shared hooks were before), which is the first step to shipping compiled output.
- **Migration:** by hand, only where code names the forwardRef type: use `typeof X` or `React.ComponentProps<typeof X>` instead (by hand)

## The names deprecated for 17.0.0 are removed (`.changeset/removed-names-17.md`)

- **What breaks:** `TimelineItem`'s `status` and the `TimelineStatus` type, `Combobox`'s `onInputChange`, and `PasswordInput`'s `visible`, `defaultVisible` and `onVisibleChange`. Each has warned in development since it was deprecated, naming its replacement.
- **Why:** one idea, one name: `tone` for a color's meaning, `onInputValueChange` for `inputValue`, and `revealed` as MaskedValue says it.
- **Migration:** `serupa-migrate` renames each one (`serupa-migrate` makes it)

## Accordion opens any number and leaves the arrow keys to the page (`.changeset/accordion-multiple-tab.md`)

- **What breaks:** an Accordion with no `type` is `"multiple"`: opening one item leaves the others open. Up, Down, Home and End no longer move between titles; Tab does, as between any buttons.
- **Why:** people compare items, and closing one as another opens takes away what they were reading; the modern web guidance says to avoid exclusive accordions, and that arrow keys on a disclosure's button should scroll the page. The WAI-ARIA pattern marks the arrow keys optional.
- **Migration:** `serupa-migrate --from 16` adds `type="single"` to each Accordion with no `type` (`serupa-migrate` makes it)
