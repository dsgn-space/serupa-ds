# RFC: 13.0.0

**Status:** Released in 13.0.0 (1 November 2026). The masks and gradients section moved to the [14.0.0 RFC](14.0.0.md): its pull request merged after 13.0.0 was cut.

The next major removes two names deprecated in 12.x, makes the dark themes a step lighter, and types the `as` prop of the navigation items the way Link's already is. Only the dark themes change what people see; the rest is renames a script makes and TypeScript types.

## Lighter dark themes (`.changeset/dark-surface-900.md`)

- **What breaks:** in the three dark themes the page is `zinc-900` instead of `zinc-950`, and each layer above it (muted, raised, overlay, field, borders, secondary) moves up one step with it. Text, brand and status colors don't change, nor do the light themes.
- **Why:** the page comes off near-black, and every layer moves with it so they stay a step apart and a field stays a step lighter than the page, with text still at WCAG 2.2 AA on each.
- **Migration:** nothing to do with the tokens. A raw `zinc-950`, `zinc-900` or `zinc-800` placed next to Serupa surfaces in dark, or a hardcoded `#09090b`, needs the token or the next step up. By hand: there's nothing a script can rename.

## IconButton `noTitle` and Table `captionHidden` removed (`.changeset/remove-notitle-captionhidden.md`)

- **What breaks:** the old names, deprecated with a warning since 12.x, stop working.
- **Why:** every boolean is named in the positive (`hideTitle`, `hideCaption`), as CONTRIBUTING asks.
- **Migration:** rename them. `serupa-migrate` makes it on the tags and lists any left in a props object.

## NavbarLink's `as` is typed (`.changeset/l8e120-navbarlink-typed-as.md`)

- **What breaks:** TypeScript only: the props are those of the component `as` names, so a prop it doesn't take is now an error.
- **Why:** `<NavbarLink as={RouterLink} to="/x">` didn't type-check without a cast, and a misspelled `to` went unnoticed.
- **Migration:** remove the casts and spreads that got router props past the old types. By hand.

## SidebarItem's `as` is typed (`.changeset/l8e121-sidebaritem-typed-as.md`)

- **What breaks, why, migration:** as for NavbarLink above.

## MenuItem's `as` is typed (`.changeset/l8e122-menuitem-typed-as.md`)

- **What breaks, why, migration:** as for NavbarLink above. MenuItem's guide already promised it.
