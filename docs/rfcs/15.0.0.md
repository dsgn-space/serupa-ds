# RFC: 15.0.0

**Status:** Scheduled. Open for comments.

The first scheduled major (CONTRIBUTING.md, Release cadence and support). It removes names that were deprecated at least four weeks earlier, so one prop means one thing everywhere (the API naming table), and it settles what the package promises about its token tiers and where it lives. Every breaking changeset until its release adds a section here.

## Planned

These are agreed and wait for their merge requests. Each becomes a section with its changeset when it lands.

- **One name for one idea (GR268).** Each prop in `NAME_GAPS` (`tools/test/props.mjs`) gets the naming table's name as an alias in a 14.x minor, with the old name deprecated. Those are Fab and Toaster `position` (to `placement`), Field `layout` and Splitter `direction` (to `orientation`), Switch `pending` (to `loading`), and Tooltip `delay` (to `openDelay`). Select gets `onValueChange` beside its native `onChange`, Timeline `tone` beside `status`, and Text's `tone="default"` becomes its real default. 15.0.0 then only removes the old names, at least 28 days after the minor (`deprecations.mjs` enforces it).
- **Primitive tokens are a tier of their own.** The README's Versioning table will say that palette and effect primitives outside the semantic layer (208 of the 635 typed tokens, which no component or theme reads) may change in a minor release, and they will stay out of the Figma and native exports. They aren't deleted. The semantic and component tokens keep the full major-only promise.
- **The package points at GitLab.** `package.json`'s `repository`, `homepage` and `bugs` still name GitHub. They will name the GitLab project while it's the home of the code.
- **The roadmap says what's true.** `ROADMAP.md` drops the stale "rename", "Later: page patterns" and "nothing deprecated" lines.
