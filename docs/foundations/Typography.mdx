## Do and don't

| Do | Don't |
| --- | --- |
| Choose a heading's level from the page outline and its `size` from the type scale. | Skip a level to get a smaller heading, or make a paragraph big and bold to look like one. |
| Use the type styles (`type-body`, `type-label`), which carry their own line height. | Set a font size without its line height, or write one in px. |
| Keep body text at `text-base` or `text-sm`, with lines of 45 to 75 characters. | Set long reading text in `text-xs` or at full page width. |
