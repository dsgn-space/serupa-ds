## Do and don't

| Do | Don't |
| --- | --- |
| Round with the role for the part: `radius-control`, `radius-surface`, `radius-container`, `radius-inner`. | Pick a step (`rounded-lg`) for a component. `data-radius` and the brand can't change it. |
| Give something nested inside a rounded box a smaller radius (`radius-inner`), so the two curves run side by side. | Give the inside the same radius as the outside. The gap between them pinches at the corners. |
| Keep `radius-pill` for things that are meant to be pills, like badges and tags. | Round a large card into a pill. |
