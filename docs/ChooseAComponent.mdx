# Choose a component

Some components look alike but say different things to a screen reader and behave differently on the keyboard. A radio group says "one of these". Checkboxes say "any number". A switch says "on now". This page puts the look-alikes side by side, so you can pick by what people are doing. Each component's own page says more under "When not to use".

## Pick one value

| People are… | Use |
| --- | --- |
| Choosing from 2 to about 5 options they should see at once | [Radio](?path=/docs/components-forms-radio--docs) (a RadioGroup) |
| Choosing from a few options that each need a line to explain them, such as plans or delivery methods | [Radio](?path=/docs/components-forms-radio--docs) cards (a RadioGroup with `variant="card"`) |
| Choosing from a few options that change a view right away, such as Day, Week, Month | [SegmentedControl](?path=/docs/components-forms-segmentedcontrol--docs) |
| Choosing from about 5 to 10 options, where space is short | [Select](?path=/docs/components-forms-select--docs) |
| Searching a long list, such as countries or people | [Combobox](?path=/docs/components-forms-combobox--docs) |
| Choosing inside a hierarchy, one level at a time, such as province, then city, then district | [CascadeSelect](?path=/docs/components-forms-cascadeselect--docs) |
| Typing an answer that may not be in any list | [Input](?path=/docs/components-forms-input--docs) |
| Rating something with stars | [Rating](?path=/docs/components-forms-rating--docs) |

## On or off

| People are… | Use |
| --- | --- |
| Turning a setting on that applies at once, such as notifications | [Switch](?path=/docs/components-forms-switch--docs) |
| Ticking an option that is saved later, with the form's Save button | [Checkbox](?path=/docs/components-forms-checkbox--docs) |
| Turning a tool on in a toolbar, such as bold or mute | [ToggleButton](?path=/docs/components-actions-togglebutton--docs) |
| Turning several tools on or off together, such as bold, italic and underline | [ToggleGroup](?path=/docs/components-actions-togglegroup--docs) |

Never use two radios for on and off: one Checkbox or Switch says it in one control.

## Pick several values

| People are… | Use |
| --- | --- |
| Picking any number from a short list they should see at once | [Checkbox](?path=/docs/components-forms-checkbox--docs) (a CheckboxGroup) |
| Picking add-ons that each need a line to explain them, such as gift wrap or insurance | [Checkbox](?path=/docs/components-forms-checkbox--docs) cards (a CheckboxGroup with `variant="card"`) |
| Picking any number from a long list they search | [Combobox](?path=/docs/components-forms-combobox--docs) with `multiple` |
| Putting items in their own order | [SortableList](?path=/docs/components-content-sortablelist--docs) |

## Numbers, dates and times

| People are… | Use |
| --- | --- |
| Typing an exact number, such as a quantity or an amount of money | [NumberInput](?path=/docs/components-forms-numberinput--docs) |
| Setting a value where its place in a range matters more than the number, such as volume | [Slider](?path=/docs/components-forms-slider--docs) |
| Typing digits that aren't an amount: a postcode, a card number | [Input](?path=/docs/components-forms-input--docs) with the right `inputMode` |
| Typing a phone number | [PhoneInput](?path=/docs/components-forms-phoneinput--docs) |
| Typing a one-time code or a PIN | [PinInput](?path=/docs/components-forms-pininput--docs) |
| Picking a day near today, such as a delivery date | [DatePicker](?path=/docs/components-forms-datepicker--docs) |
| Typing a day they know by heart, such as a date of birth | [DateField](?path=/docs/components-forms-datefield--docs) |
| Picking a start and an end day | [DateRangePicker](?path=/docs/components-forms-daterangepicker--docs) |
| Picking a whole month, quarter or year, such as a report's month or a billing period | [PeriodPicker](?path=/docs/components-forms-periodpicker--docs) |
| Seeing a month that stays on the page, such as a booking view | [Calendar](?path=/docs/components-forms-calendar--docs) |
| Seeing events on a day, week or month, such as a team calendar | [EventCalendar](?path=/docs/components-data-display-eventcalendar--docs) |
| Picking a time of day | [TimePicker](?path=/docs/components-forms-timepicker--docs) |
| Picking a day and a time together, such as when a meeting starts | A [DatePicker](?path=/docs/components-forms-datepicker--docs) and a TimePicker in one Field group, as its "Date and time" section shows |
| Picking a color | [ColorPicker](?path=/docs/components-forms-colorpicker--docs) |
| Choosing a time zone, such as for their profile or a meeting | [TimeZonePicker](?path=/docs/components-forms-timezonepicker--docs) |

## Text

| People are… | Use |
| --- | --- |
| Typing a name, an email or another one-line answer | [Input](?path=/docs/components-forms-input--docs) |
| Typing a password | [PasswordInput](?path=/docs/components-forms-passwordinput--docs) |
| Searching | [SearchInput](?path=/docs/components-forms-searchinput--docs) |
| Writing a few sentences or more | [Textarea](?path=/docs/components-forms-textarea--docs) |
| Changing one value in place, such as a page title, without opening a form | [InlineEdit](?path=/docs/components-forms-inlineedit--docs) |
| Confirming an action that can't be undone, such as deleting a project, by typing its name | [TypeToConfirm](?path=/docs/components-forms-typetoconfirm--docs) |
| Signing, such as a delivery or a consent form, with a typed name always on offer | [SignaturePad](?path=/docs/components-forms-signaturepad--docs) |
| Adding files, by choosing or dropping them | [FileUpload](?path=/docs/components-forms-fileupload--docs); each file it lists, or one sent in a message, is an [Attachment](?path=/docs/components-content-attachment--docs) |

Wrap every form control in a [Field](?path=/docs/components-forms-field--docs), which gives it its label, hint and error. When a form is sent with errors, put an [ErrorSummary](?path=/docs/components-forms-errorsummary--docs) at its top.

## Actions and links

| People are… | Use |
| --- | --- |
| Doing something: saving, sending, opening a dialog | [Button](?path=/docs/components-actions-button--docs) |
| Going somewhere: another page or a place on this one | [Link](?path=/docs/components-actions-link--docs) in text, or a [Button](?path=/docs/components-actions-button--docs) with `href` for a call to action |
| Doing something with a well-known icon and no room for words, such as close | [IconButton](?path=/docs/components-actions-iconbutton--docs) |
| Doing the one main action of a screen on a phone, such as Compose | [Fab](?path=/docs/components-actions-fab--docs) |
| Copying a key, a link or a command | [CopyButton](?path=/docs/components-actions-copybutton--docs) |
| Choosing from a list of actions behind one button | [Menu](?path=/docs/components-overlays-menu--docs) |
| Using a set of related actions, such as an editor's formatting | [Toolbar](?path=/docs/components-actions-toolbar--docs) |
| Giving an editor or tool its File, Edit and View menus along the top | [Menubar](?path=/docs/components-overlays-menubar--docs) |
| Using a few related buttons joined together | [ButtonGroup](?path=/docs/components-actions-buttongroup--docs) |

The rule: a Button does, a Link goes. A link that runs code, or a button that changes the URL, breaks the back button, middle-click and screen readers' lists of links.

## Things that open over the page

| People need… | Use |
| --- | --- |
| A short hint about a control, such as what an icon button does | [Tooltip](?path=/docs/components-overlays-tooltip--docs) |
| A sentence or two explaining a term, a setting or where a value comes from, opened by pressing a "?" or "i" (touch and keyboard too) | [ContextualHelp](?path=/docs/components-overlays-contextualhelp--docs) |
| A preview of a person, page or record while pointing at or focusing its link | [HoverCard](?path=/docs/components-overlays-hovercard--docs) |
| A few controls or details next to the button that opens them, while the page stays usable | [Popover](?path=/docs/components-overlays-popover--docs) |
| A list of actions | [Menu](?path=/docs/components-overlays-menu--docs) |
| To answer a question or finish a short form before going on | [Dialog](?path=/docs/components-overlays-dialog--docs) |
| A long form, filters, or details they check while looking at the page | [Drawer](?path=/docs/components-overlays-drawer--docs) |
| The messages that came in while they were away | [NotificationCenter](?path=/docs/components-overlays-notificationcenter--docs) |
| The list of the app's keyboard shortcuts | [KeyboardShortcuts](?path=/docs/components-overlays-keyboardshortcuts--docs) |
| To jump to any page or action by typing its name | [CommandPalette](?path=/docs/components-overlays-commandpalette--docs) (to search the content of one list or page, a SearchInput) |
| A short guided walk past the main parts of a new screen | [Tour](?path=/docs/components-overlays-tour--docs) |

Nothing anyone needs to do the task goes only in a Tooltip: touch screens never show it, and nothing inside it can be reached. When an explanation needs to reach everyone, or hold a link, use ContextualHelp; when it's needed to finish the task, put it on the page.

## Messages and status

| People need to know… | Use |
| --- | --- |
| That something just happened, such as "Link copied", with Undo at most | [Toast](?path=/docs/components-feedback-toast--docs) |
| Something about the page or a task, which stays until it's fixed or dismissed | [Alert](?path=/docs/components-feedback-alert--docs) |
| What is wrong with one field | The `error` of its [Field](?path=/docs/components-forms-field--docs) |
| What is wrong with a whole form that was sent | [ErrorSummary](?path=/docs/components-forms-errorsummary--docs) |
| A short status, a count or a category, in a table or on a card | [Badge](?path=/docs/components-feedback-badge--docs) |
| That their changes are being saved, or were, without a Save button | [SaveStatus](?path=/docs/components-feedback-savestatus--docs) |
| That the connection dropped, and that it came back | [OfflineBanner](?path=/docs/components-feedback-offlinebanner--docs) |
| That a page or a panel is empty, and what fills it | [EmptyState](?path=/docs/components-feedback-emptystate--docs) |
| That one part of the page broke, without losing the rest | [ErrorBoundary](?path=/docs/components-feedback-errorboundary--docs) |

## Waiting and amounts

| People are… | Use |
| --- | --- |
| Waiting for something you can't measure, such as content loading | [Loader](?path=/docs/components-feedback-loader--docs) |
| Waiting for something you can measure, such as an upload | [Progress](?path=/docs/components-feedback-progress--docs) |
| Waiting on a button's own action | [Button](?path=/docs/components-actions-button--docs) with `loading` |
| Reading an amount within known limits, such as storage used | [Meter](?path=/docs/components-feedback-meter--docs) |
| Reading a count with no maximum, such as unread messages | [Badge](?path=/docs/components-feedback-badge--docs) |

## Moving around

| People are… | Use |
| --- | --- |
| Moving between the app's main pages | [Navbar](?path=/docs/components-navigation-navbar--docs) or [Sidebar](?path=/docs/components-navigation-sidebar--docs) |
| Moving between 3 to 5 main pages on a phone, with a thumb | [BottomNav](?path=/docs/components-navigation-bottomnav--docs) (on a wide screen, the Navbar or Sidebar instead) |
| Jumping to a section of a long page, such as a guide | [TableOfContents](?path=/docs/components-navigation-tableofcontents--docs) |
| Going back up the pages above this one | [Breadcrumb](?path=/docs/components-navigation-breadcrumb--docs) |
| Switching between views of the same thing, on one page | [Tabs](?path=/docs/components-navigation-tabs--docs) |
| Opening and closing sections, such as FAQs | [Accordion](?path=/docs/components-content-accordion--docs) |
| Going through steps in order, such as a checkout | [Stepper](?path=/docs/components-navigation-stepper--docs) |
| Moving through pages of results they may come back to or link to | [Pagination](?path=/docs/components-navigation-pagination--docs) |
| Reading on through a feed, without caring which page they're on | [LoadMore](?path=/docs/components-navigation-loadmore--docs) |
| Moving through nested items, such as folders | [TreeView](?path=/docs/components-navigation-treeview--docs) |
| Looking through slides one at a time | [Carousel](?path=/docs/components-content-carousel--docs) |

## Showing a collection

| The items are… | Use |
| --- | --- |
| A line or two of text each, such as people or files | [List](?path=/docs/components-content-list--docs) |
| Data with columns to compare or sort | [Table](?path=/docs/components-content-table--docs) |
| Data people edit cell by cell, or copy to and from a spreadsheet | [DataGrid](?path=/docs/components-content-datagrid--docs) |
| Pairs of a label and a value, such as an order's details | [DescriptionList](?path=/docs/components-content-descriptionlist--docs) |
| Thousands of rows, too many for a List or Table to draw at once | [VirtualList](?path=/docs/components-content-virtuallist--docs) |
| Cards that move between stages, such as tasks from To do to Done | [Kanban](?path=/docs/components-content-kanban--docs) (for one list people reorder, a SortableList) |
| Rows narrowed by a few filters people add and remove, such as Status is Open | [FilterBar](?path=/docs/components-forms-filterbar--docs) above the List or Table |
| Long text each, such as reviews or descriptions, opened in place | [ShowMore](?path=/docs/components-content-showmore--docs) |
| Long text each, as a preview that links to the full item | [Text](?path=/docs/components-layout-and-type-text--docs) with `lines` |
| Pictures or a lot of content each | [Card](?path=/docs/components-content-card--docs)s in a [Grid](?path=/docs/components-layout-and-type-grid--docs) |
| A trend over time, or amounts to compare across a few categories | [Chart](?path=/docs/components-data-display-chart--docs) |
| A trend in the space of a word, such as in a table cell or next to a number | [Sparkline](?path=/docs/components-data-display-sparkline--docs) |
| Events in order of time | [Timeline](?path=/docs/components-data-display-timeline--docs) |
| Messages in a conversation, such as a support chat | [Chat](?path=/docs/components-content-chat--docs) |
| Lines of code to read or copy, such as an install command | [CodeBlock](?path=/docs/components-content-codeblock--docs) |

[Grid](?path=/docs/components-layout-and-type-grid--docs) and [Stack](?path=/docs/components-layout-and-type-stack--docs) lay out the page. A Table is for data only.

## Pictures and people

| Showing… | Use |

## Layout

| People need… | Use |
| --- | --- |
| Two panes side by side, sized by dragging, such as a list and its detail | [Splitter](?path=/docs/components-layout-splitter--docs) |
| A side panel that opens over the page and closes again | A Drawer (one that stays, the Sidebar) |
| A box of its own that scrolls, such as a long list in a panel | [ScrollArea](?path=/docs/components-layout-and-type-scrollarea--docs) |
